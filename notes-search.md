# Notes Search and Filtering

## Overview
The search and filtering feature helps users find their saved notes quickly and easily.

## Features

1. **Search Notes:** Users can search notes using their title or keywords.
2. **Filter by Category:** Users can select a category to display only notes belonging to it.
3. **Empty Search Query:** When the search field is empty, all notes are displayed. If a category is selected, only notes from that category are displayed.
4. **Combined Search and Filter:** Users can search for keywords within a selected category.
5. **No Results Message:** Display a helpful message when no matching notes are found.
6. **Clear Filters:** Allow users to reset the search and category filters to display all saved notes.

## Expected Behaviour

- Search results should update according to the entered keyword.
- Selecting a category should display only relevant notes.
- Search and category filters should work together.
- An empty search field should display all notes matching the selected category.
- Clearing filters should display all saved notes again.

## Benefit
This feature improves note organisation and saves users time when locating specific notes.
